# XV Tadeo — 10 pases

Cada carpeta (`1` a `10`) contiene:
- `index.html`
- `portada.png`

Cada portada tiene un área táctil sobre el texto "HAZ CLICK PARA ABRIR LA INVITACIÓN".
Al tocarla, abre la invitación completa de Canva:

https://invitaciones-digitales-lg.my.canva.site/copia-de-copia-de-brissa-y-antonio-definitivo

## Publicación en GitHub Pages

Sube TODO el contenido de esta carpeta a un repositorio de GitHub y activa GitHub Pages.

Después, si el repositorio se llama `invitacion-tadeo`, las rutas serán:

- `https://TU-USUARIO.github.io/invitacion-tadeo/1/`
- ...
- `https://TU-USUARIO.github.io/invitacion-tadeo/10/`

La invitación completa continúa alojada en Canva, por lo que sus botones interactivos siguen funcionando.
